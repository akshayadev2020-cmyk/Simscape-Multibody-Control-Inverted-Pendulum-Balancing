# Simscape-Multibody-Control-Inverted-Pendulum-Balancing

1) Stabilized a Simscape Multibody mechanical model of an inverted pendulum by extracting system states and implementing an
   optimal Linear Quadratic Regulator (LQR) control law.
2) Tuned the Q and R weighting matrices to achieve stable balancing of the simulated mechanical assembly and analyzed the resulting
   cart motion and response plots.
